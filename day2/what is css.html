css는 HTML 문서의 디자인과 레이아웃을 정하는 언어 HTML이 웹페이지의 구조와 내용을 만든다면 css는 그 요소들의 색상,글꼴,크기,간격 등을 꾸며줌 선택자(Selector): 스타일을 적용할 대상 (예: h1) 속성(Property): 바꿀 스타일 종류 (예: color) 값(Value): 속성에 줄 값 (예: blue) 각 선언은 세미콜론 ;으로 끝나고, 주석은 /* */로 사용 Cascading(계단식)의 의미 같은 요소에 여러 스타일이 겹치면 우선순위에 따라 하나가 적용되고, 부모 요소의 일부 스타일(글자색, 글꼴 등)은 자식에게 상속 Inline CSS (인라인) :HTML 태그 안에 style 속성으로 직접 작성 장점: 특정 요소 하나만 빠르게 바꿀 때 편하고, 우선순위가 가장 높음 단점: 재사용이 안 되고, 코드가 HTML과 섞여 유지보수가 어려움 Internal CSS (내부): HTML 문서의 안에
